What is the time complexity of the following code :

```python
for i in range(1, 101, i * 2):
    for j in range(1, n + 1):
        print(i + j, end=' ')
    print()
```
# # # ANSWER
O(n)
# # # EXPLANATION
The outer loop runs a constant number of times (specifically 7 times, as `i` takes values 1, 2, 4, 8, 16, 32, and 64). The inner loop runs `n` times. Therefore, the overall time complexity is O(n).
