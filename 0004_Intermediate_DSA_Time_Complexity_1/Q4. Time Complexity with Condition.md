What is the time complexity of the following code :

```python
def func(n):
    s = 0
    i = 0
    while i < n:
        s = s + i
        i = i * 2
    return s
```
# # ANSWER
O(infinity)
# # EXPLANATION
The loop will run indefinitely because `i` starts at 0 and is multiplied by 2 in each iteration. Since `i` will always be 0, the condition `i < n` will always be true, leading to an infinite loop. Therefore, the time complexity is considered O(infinity).
