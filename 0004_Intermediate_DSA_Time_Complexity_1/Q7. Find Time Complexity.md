What is the time complexity of the following code :

```python
for i in range(1, n + 1, i * 2):
    for j in range(1, n + 1):
        print(i + j, end=' ')
    print()
```

## # # # # ANSWER
O(n log n)
## # # # # EXPLANATION
The outer loop runs `log n` times because `i` is multiplied by 2 in each iteration. The inner loop runs `n` times for each iteration of the outer loop. Therefore, the total time complexity is O(n log n).
