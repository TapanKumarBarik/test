Given A = [1, -2, 5, 2, -

, 6]. Choose all the valid subarrays of the array


[5, 2, -1]


[-2, -1, 6]


[1, -2, 5, 2]


[6]

# Answer
[5, 2, -1]

[1, -2, 5, 2]

[6]

# Explanation
# What is subarray
### A subarray is a contiguous part of an array. It can be empty or contain all elements.
### A subarray is defined by two indices, start and end, where start <= end.
